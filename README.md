# FastExclude for Senler & Salebot (Google Chrome Extension v7.4)

Расширение для браузера Google Chrome (Manifest V3), автоматизирующее выбор групп-исключений, авто-заполнение и массовое копирование завершённых рассылок в интерфейсе сервисов рассылок **Senler (VK)** и **Salebot (Telegram)**.

Выполнено в стиле **Next-Gen 2026 Dark Terminal UI** с динамической неоновой подсветкой и идеальной геометрией.

---

## 🎨 Дизайн-концепт Next-Gen 2026 Dark UI

Интерфейс расширения спроектирован по гайдлайнам ультрасовременных инструментов разработчиков и маркетологов:
- **Цветовая палитра**: Глубокий тёмно-угольный фон (`#09090b`), графитовые карты (`#121215`), изумрудно-зеленый неоновый акцент (`#10b981`) для Senler (VK), лазурный акцент (`#0088cc`) для Salebot (Telegram), сдержанный фоновый текст (`#a1a1aa` / `#f4f4f5`).
- **Типографика**: Современный геометрический гротеск (`Plus Jakarta Sans` / `Inter`) и моноширинный шрифтовой акцент (`JetBrains Mono`).

- **Элевация и свечение**: Мягкие неоновые ореолы при выборе активных платформ и плавные микро-анимации наведения (`translateY(-2px)`).

## 🚀 Основной функционал

### 0. 🌐 Выбор платформы (Senler VK / Salebot Telegram)
- **Экран выбора**: При первоначальном запуске вы можете выбрать целевую платформу:
  - 💚 **Senler (ВКонтакте)**: Полный функционал авто-исключений, заполнения и копирования рассылок VK.
  - 🤖 **Salebot (Telegram)**: Поддержка авто-рассылок и цепочек в кабинете Salebot.
- **Быстрое переключение**: Компактная кнопка `[ 💙 Senler ▾ ]` или `[ ✈️ Salebot ▾ ]` в шапке позволяет мгновенно изменить платформу в любой момент.

### 1. ⚡ Режим «Исключения» (Exclusions Mode)
Автоматизирует исключение определенных групп подписчиков при настройке рассылки.
- **Создание и редактирование пресетов**: Позволяет вводить название пресета и список названий исключаемых групп (по одной на строку).
- **Умное сопоставление (Advanced Normalizer)**: Очищает названия групп от лишних символов (`/`, `.`, `-`, кавычки), нивелирует разницу между `ё` и `е`.
- **Выбор области применения**: Заполнение только текущей вкладки или параллельное выполнение во всех открытых вкладках.
- **Интерактивный отчет о выполнении**: Модальное окно со детальной таблицей результатов и кнопкой копирования не найденных групп.

### 2. ✉️ Режим «Создание рассылки» (Mailings Mode)
Позволяет в один клик полностью заполнить форму создания новой рассылки.
- **Поля ввода**: Название, Текст сообщения (с форматированием и прикреплением фото PNG/JPG/WEBP), Дата и Время, Пресет исключений.
- **Массовое заполнение**: Применяет шаблон ко всем открытым вкладкам рассылок в один клик.

### 3. 📋 Режим «Копирование рассылки» (Clone Mode)
Автоматически находит свежайшую завершённую рассылку по ключевому слову и запускает её копирование.
- **Кастомные пресеты копирования**: Быстрые кнопки для частых ключевых слов (*Родители*, *СШ*, *ЕГЭ*, *ОГЭ*) с возможностью добавлять и удалять собственные пресеты.
- **Параллельное дублирование**: Запуск поиска и копирования во всех открытых вкладках Senler одновременно.

## 🚀 Инструкция по установке в Google Chrome (Режим разработчика)

1. **Скачайте или перейдите в папку проекта**:
   Путь к папке проекта: `c:\Users\DIMA\Desktop\ai\FastExclude`

2. **Откройте страницу расширений в Chrome**:
   - Введите в адресной строке браузера: `chrome://extensions/` и нажмите `Enter`.
   - Или нажмите меню Chrome (три точки в правом верхнем углу) ➔ **Расширения** ➔ **Управление расширениями**.

3. **Включите "Режим разработчика" (Developer mode)**:
   - В правом верхнем углу страницы `chrome://extensions/` включите переключатель **Режим разработчика**.

4. **Загрузите распакованное расширение**:
   - Нажмите кнопку **"Загрузить распакованное"** ("Load unpacked") в левом верхнем углу.
   - Укажите папку `FastExclude` (`c:\Users\DIMA\Desktop\ai\FastExclude`) и нажмите **"Выбор папки"**.

5. **Готово!**
   - Расширение появится в списке установленных под названием **FastExclude for Senler**.
   - Закрепите иконку расширения на панели инструментов браузера для быстрого доступа.
