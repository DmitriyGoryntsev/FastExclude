# FastExclude for Senler (Google Chrome Extension)

Расширение для браузера Google Chrome (Manifest V3), автоматизирующее выбор групп-исключений и массовое создание рассылок в интерфейсе сервиса рассылок **Senler** (VK).

Выполнено в эксклюзивном визуальном стиле **Caldera** («Теплый известняк и магматический оранжевый»).

---

## 🎨 Дизайн-концепт Caldera

Интерфейс расширения спроектирован по гайдлайнам дизайн-системы Caldera:
- **Цветовая палитра**: Теплый серый фон холста (Pumice `#e2e2df`), подложки карточек цвета известняка (Limestone `#f7f6f2`), раскаленный оранжевый акцент для ключевых действий (Ember `#fc5000`), серно-желтый для бэджей и счетчиков (Sulfur `#f5f28e`) и глубокий черный Obsidian (`#070607`) для обводок и контрастного текста.
- **Типографика**: Мощные заголовки в индустриальном стиле (`Bebas Neue`) и чистый, геометричный шрифт для кнопок и полей (`DM Sans 500 Medium`).
- **Скругления (Triple-Radius)**: 32px для карточек и модальных окон, 100px для полей ввода, 800px (Pill) для кнопок и бэджей.
- **Shadowless**: Полное отсутствие теней. Иерархия создается за счет контрастности элементов и жестких обводок.

## 🚀 Основной функционал

Расширение разделено на два независимых режима работы (вкладки переключения вверху):

### 1. ⚡ Режим «Исключения» (Exclusions Mode)
Автоматизирует исключение определенных групп подписчиков при настройке рассылки.
- **Создание и редактирование пресетов**: Позволяет вводить понятное название пресета (например, *Исключения для рассылки СШ*) и список названий исключаемых групп (каждое с новой строки). Пресеты сохраняются в `chrome.storage.local` и синхронизируются при перезапуске браузера.
- **Умное сопоставление (Advanced Normalizer)**: Очищает названия групп от лишних слэшей (`/`), точек (`.`), тире, кавычек, скобок, нивелирует разницу между `ё` и `е`, что гарантирует 100% совпадение для таких названий, как `2025/2026 уч.год` и `2025 / 2026 уч. год`.
- **4 стратегии поиска селектора**: Автоматически определяет Select2 для исключений на странице по сложным приоритетам (data-атрибуты, текстовый контекст лейблов «За исключением / Кроме», name/id селектора).
- **Выбор области применения**: При клике на кнопку «Применить» у пресета открывается меню:
  - *Только к этой вкладке*: Заполняет активную страницу Senler.
  - *Ко всем открытым вкладкам Senler*: Параллельно заполняет выбранный пресет во всех открытых вкладках предметных рассылок в один клик.
- **Интерактивный отчет о выполнении**: Отображает модальное окно с наглядной статистикой (сколько групп добавлено, сколько не найдено) и детальной таблицей.
- **Копирование не найденных**: Возможность в один клик скопировать в буфер обмена все группы из пресета, которые не удалось обнаружить в кабинете Senler.

### 2. ✉️ Режим «Создание рассылки» (Mailings Mode)
Позволяет в один клик полностью заполнить форму создания новой текстовой рассылки.
- **Шаблон рассылки**: Поля ввода для *Названия рассылки*, *Текста сообщения*, *Даты и времени отправки* и выпадающий список ваших пресетов исключений.
- **Поддержка Emoji-редактора (EmojioneArea)**: Скрипт корректно обходит кастомные редакторы эмодзи в интерфейсе Senler и заполняет визуальный блок редактора наряду с системным `<textarea>`.
- **Массовое заполнение**:
  - *Заполнить текущую вкладку*: Применяет текстовый шаблон к активной странице.
  - *Заполнить все вкладки Senler*: Моментально разносит название, текст сообщения, дату отправки и списки исключений по всем 12 открытым вкладкам Senler в один клик.
- **Автосохранение черновика**: Введенные данные рассылки автоматически сохраняются при вводе и не теряются при закрытии popup-окна расширения.

### 3. Дополнительные сервисные функции
- **Поиск по пресетам**: Удобный фильтр пресетов по названию прямо в списке.
- **Статистика**: Дашборд с количеством пресетов, общим числом групп и текущим статусом работы.
- **Резервное копирование (JSON)**: Кнопка экспорта пресетов в файл на компьютер и функция импорта JSON файлов для быстрого обмена пресетами между маркетологами.
- **Toast-уведомления**: Плавные всплывающие подсказки обо всех успешных операциях и ошибках.

## 🚀 Инструкция по установке в Google Chrome (Режим разработчика)

1. **Скачайте или перейдите в папку проекта**:
   Путь к папке проекта: `c:\Users\DIMA\Desktop\ai\FastExclude`

2. **Откройте страницу расширений в Chrome**:
   - Введите в адресной строке браузера: `chrome://extensions/` и нажмите `Enter`.
   - Или нажмите меню Chrome (три точки в правом верхнем углу) ➔ **Расширения** ➔ **Управление расширениями**.

3. **Включите "Режим разработчика" (Developer mode)**:
   - В правом верхнем углу страницы `chrome://extensions/` включите переключатель **Режим разработчика**.

4. **Загрузите распакованное расширение**:
   - Нажмите кнопку **"Загрузить распакованное"** ("Load unpacked") в левом верхнем углу.
   - Укажите папку `FastExclude` (`c:\Users\DIMA\Desktop\ai\FastExclude`) и нажмите **"Выбор папки"**.

5. **Готово!**
   - Расширение появится в списке установленных под названием **FastExclude for Senler**.
   - Закрепите иконку расширения на панели инструментов браузера для быстрого доступа.
